# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/69cd8dd2-0ebd-40dc-a68f-fb5a853b5d8b

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Levantar la API institucional (`backend/`, puerto 4000). Vite redirige `/api` a ese puerto.
3. Run the app:
   `npm run dev`
4. Ingresar con una cuenta con rol STUDENT_REP (Centro de Estudiantes) o SUPER_ADMIN.
