Sistema de Preceptoría Escolar

Handbook Oficial del Prototipo

1. Visión General

Este proyecto es un prototipo demostrativo desarrollado para la gestión y seguimiento de alumnos por parte del área de preceptoría. Forma parte de una arquitectura mayor en la que el Sistema de Preceptoría consume datos de un sistema centralizado de asistencia mediante llamadas a una API.

El objetivo principal es brindar herramientas para monitorear inasistencias, registrar justificaciones, visualizar llegadas tarde y generar alertas automáticas para alumnos que requieran atención institucional.

2. Stack Tecnológico

Next.js (App Router)

Framework de React para renderizado y enrutamiento avanzado, permitiendo API Routes integradas.

React & TypeScript

Construcción de interfaces robustas y tipadas para evitar errores en tiempo de ejecución.

Tailwind CSS

Framework de utilidades CSS para diseño responsive, animaciones fluidas y estética Glassmorphism.

SQLite (better-sqlite3)

Base de datos embebida ligera, optimizada con índices, ideal para prototipos locales demostrativos.

3. Módulos del Sistema

Dashboard Principal

Panel de control con métricas en tiempo real: total de alumnos, porcentajes de asistencia diarios y atajos a situaciones urgentes.

Gestión de Alumnos

Buscador con filtros por curso. Al acceder al perfil de un alumno, se consolida su historial completo de asistencia, justificaciones y observaciones disciplinares.

Módulos de Asistencia

Secciones para consultar Asistencia General, registrar y ver Llegadas Tarde, y un panel de Control de Inasistencias.

Justificaciones y Seguimiento

Flujo de aprobación y rechazo de justificaciones pendientes. El panel de alertas detecta automáticamente a estudiantes con múltiples inasistencias o demoras.

4. Base de Datos y APIs

El sistema implementa Route Handlers en Next.js para aislar la base de datos del cliente, simulando un microservicio:

  • /api/dashboard: Retorna estadísticas agregadas.
  • /api/alumnos y /api/alumnos/[id]: Datos relacionales de estudiantes.
  • /api/justificaciones: (GET y POST) Lectura y modificación de estados.
  • /api/seguimiento: Consultas de advertencias usando cláusulas HAVING COUNT.

Esquema Relacional Básico

cursos (id, anio, division)
alumnos (id, nombre, apellido, dni, curso_id)
asistencias (id, alumno_id, fecha, estado: PRESENTE | AUSENTE | TARDE)
justificaciones (id, asistencia_id, estado: PENDIENTE | APROBADA | RECHAZADA, motivo, observacion)
observaciones (id, alumno_id, fecha, texto, preceptor)

5. Cómo Ejecutar el Proyecto

  1. Abre una terminal y ubícate en la raíz del proyecto.
  2. Instala las dependencias necesarias si aún no lo has hecho:
    npm install
  3. Inicia el servidor en modo desarrollo:
    npm run dev
  4. Abre tu navegador en http://localhost:3000.

    Nota: Al ejecutar por primera vez, el sistema autogenerará el archivo preceptoria.db con todos los datos necesarios para la demostración.
