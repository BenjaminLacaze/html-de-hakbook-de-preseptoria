# Módulo Alumno — Lucia

Proyecto de Lucia para el módulo de consulta del alumno dentro de un sistema de asistencia escolar. La propuesta se centra en el acceso seguro y de solo lectura a la información propia y al historial de asistencia; incluye documentación funcional, técnica y de planificación.
